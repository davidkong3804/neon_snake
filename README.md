# CYBER SNAKE // 霓虹科幻貪食蛇

一個精美、現代、霓虹科幻風格的網頁版貪食蛇遊戲。後端基於 Node.js (Express)，前端使用 HTML5 Canvas、Vanilla CSS 及原生 JavaScript 開發。

遊戲整合了 **必勝策略（Shortcutted Hamiltonian Cycle 捷徑漢米頓迴路）AI 自動導航**，貪食蛇在此模式下能自動吃到飽、完美通關填滿整個地圖而絕對不會自殺！

---

## 🎮 遊戲特色

1. 🤖 **捷徑漢米頓迴路 AI（必勝自動導航）**：
   - **數學必勝保證**：預先計算一條能遍歷 24x24 網格中所有單元格且首尾相連的漢米頓迴路（Hamiltonian Cycle）。只要蛇沿著這條迴路走，就絕對不會撞牆或撞到自己。
   - **動態尋路捷徑**：如果僅僅死板地走完迴路會非常慢。AI 會在每一步使用廣度優先搜尋 (BFS) 尋找前往食物的「捷徑」，並且在後端動態計算安全條件：**只有在「捷徑」不會跳過蛇身且能安全連回尾部時，才會走捷徑**。這實現了「既快又絕對安全」的完美尋路。
   - **手動覆蓋 (Manual Override)**：開啟自動導航後，玩家隨時按下 `W/A/S/D` 或 `方向鍵`，AI 就會瞬間停用，無縫交回手動控制。

2. 🔊 **純程式碼音效合成 (Web Audio API)**：
   - 不需要載入任何外部音訊資源，完全使用 Web Audio API 在瀏覽器中動態合成吃食物、金幣、減速與死亡的街機風復古音效。

3. 🎨 **多種塗裝與視覺效果**：
   - 包含多種外觀塗裝：霓虹綠、閃電藍、彩虹霓虹（動態 HSL 漸變）、黃金脈衝、以及科技漸層。
   - 豐富的粒子噴發特效與畫面震動特效。

4. 🏆 **本地伺服器排行榜**：
   - 使用 Node.js + Express 建立 API 端口，自動保存玩家的最高分至本機 `scores.json` 檔案中。

5. 📱 **自適應與行動端支援**：
   - 提供玻璃擬態 (Glassmorphism) 的 Cyber 儀表板，並在偵測到觸控螢幕時自動顯示大型觸控方向鍵。

## 🛠️ 執行說明

### 1. 安裝依賴
確保已安裝 Node.js，然後在專案根目錄下執行：
```bash
npm install
```

### 2. 啟動伺服器
執行以下指令啟動 Express 伺服器：
```bash
npm start
```
伺服器將在 `http://localhost:8000` 啟動。

### 3. 開始遊玩
在瀏覽器中開啟 [http://localhost:8000](http://localhost:8000) 即可開始遊玩！

## 🤖 AI 必勝演算法說明

漢米頓迴路在任意圖形中尋找是 NP-Complete 問題，但對於偶數邊長的正方形網格（如本遊戲的 24x24 網格，共 576 格），我們可以非常高效地生成一個蛇形（Zigzag）閉合迴路：

1. **基礎迴路**：
   - 第一行（y=0）從左向右拉直通往最右側。
   - y=1 至 y=23 的區域則透過「左到右、右到左」的蛇形折返填滿。
   - 最後沿著第 0 列（x=0）由下而上筆直連回起點 `(0,0)`。

2. **捷徑安全判定**：
   定義蛇頭在迴路中的索引為 $H_{idx}$，蛇尾的索引為 $T_{idx}$。
   任何相鄰單元格 $A$ 在迴路中的索引為 $A_{idx}$。如果滿足以下條件，表示從蛇頭跳躍至 $A$ 是安全的捷徑：
   $$\text{cycle\_distance}(H_{idx}, A_{idx}) < \text{cycle\_distance}(H_{idx}, T_{idx})$$
   這表示該單元格 $A$ 位於蛇頭和蛇尾之間的「空閒迴路段」中，從 $A$ 沿著迴路往後走保證能安全回到蛇尾，絕不會撞到蛇身。

3. **尋路最佳化**：
   AI 會以 BFS 搜尋一條完全由「安全捷徑點」構成的前往食物路徑。若找不到或此時蛇身過長，則退而求其次，乖乖沿著預設漢米頓迴路走一步（$H_{idx} + 1$）。此策略保證通關。
